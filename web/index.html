关于数据 / 指标说明
  • K 线来自 Hyperliquid candleSnapshot。成交量是 Hyperliquid 自家，不是 Binance / Coinbase。
  • 真实仓位 / 账户价值来自 Hyperliquid clearinghouseState 最近一次抓取，是交易所侧的权威值。
  • 重建仓位由 fills 逐条累加而来：B 增加多头、A 减少多头（变空头）。如顶部"校验"不匹配，请检查 fills 方向解析或增量是否完整。
  • 实际杠杆（带方向）= 仓位名义价值 / 账户总价值。正值为多头，负值为空头。例：-0.0263 意为 2.63% Short。
  • 挂单对账户的百分比= 订单 名义价值 / 当时账户价值，不是占当前持仓的百分比。
  • 箭头标记：▲ 暗绿 = 被动买，▲ 亮橙 = 主动买（taker buy）；▼ 暗红 = 被动卖，▼ 洋红 = 主动卖（taker sell）。主动 = crossed=true，通常对应 market-like 行为。"即将到来的市价成交"会提前 3 根 K 线在右侧面板上提示。
  • 有些订单只能从 historicalOrders 的 2000 条滚动窗口里取到，更早的订单可能已经掉出窗口——数据库会把抓到过的所有订单永久保存。配合 weekly snapshot + fills 反推，Paul 的订单 lifecycle 实际是完整记录的。
  • 主图上的挂单线段从选中时刻向右延伸（右侧 = 未来），延伸到该挂单的结束时间（成交/撤销时点）；当前仍在挂的延伸到图右端。实线 = 已成交（命中）；点线 = 未成交（包括"已被撤销"和"当前还在挂、未来未知"两种情况）。挂单详细信息在右侧表格的 badge 中区分。
